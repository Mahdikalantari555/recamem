# Design

The coordinator maintains a durable, versioned intake ledger over approved local teach/ingest events, with source IDs, permissions, timestamps and content hashes. Explicit teaching can update existing attributed memory immediately through existing APIs; updating model weights is a separate asynchronous, gated operation. Web research remains independently opt-in, unverified and security-gated. Conversations and private files are not silently used for training: sources must be authorized, scoped and revocable. The user can inspect provenance and exclude future use; past checkpoint influence may require rollback/retraining rather than promising exact unlearning.

A singleton local supervisor owns a durable queue and lease/lock; bounded CPU-only jobs run in subprocesses with configurable thread, memory, disk and time caps. Start when an enabled service is running, resume from durable job state on restart, recover expired leases idempotently, pause when no approved data or insufficient resources, and back off on failure. Never promise activity with the host off, app stopped or no OS service. The UI/API expose enabled/paused/blocked/running/failed and last success, actual model and resources; no pretend status. Pause stops scheduling and cancels or safely drains work. Across processes enforce one writer and avoid modifying an active inference checkpoint.

Planner chooses only among locally installed, compatible, licensed candidates, tokenizer and training parameters using fixed rules and recorded resource estimates; it must fail clearly when prerequisites or safe candidates are absent. Self-configuring does not require unconstrained model-generated commands, Internet downloads or arbitrary code. Preserve checkpoint/tokenizer compatibility and never silently swap model or lose facts. Existing C4/byte smoke default is merely a manual pipeline test, not an autonomous planner. Allow optional advanced override without requiring users to select internal details.

Train from approved new examples mixed with bounded replay; isolate validation data and retain attribution. Write candidate checkpoints atomically away from the active one. On independently held-out tests, compare to current model and replay controls for regression, retention, contradictions, and resource limits; promote only if predefined measurable gates pass, otherwise retain active model and evidence. Persist optimizer/RNG/state, queue offsets and manifest as a coherent version, and provide rollback. Handle duplicate input, partial writes, disk full, cancellation, malicious data, invalid models and schema upgrades without data loss. Stable active model serves inference during training; no training on untrusted instructions as code.

Initial milestone is specification and truthful UX defaults, not an enabled daemon. Later milestones implement intake and supervisor, native-generation integration, candidate training and evaluation, then surfaces and opt-in service startup. Benchmark actual 16 GB CPU hardware, quality, retention, unattended recovery and contention before declaring always-on learning supported.
