# Design

## Relation to current code
Extend `SearchLearner`, the search-provider interface and the existing provenance and lifecycle contracts. Current `adaptation/web-grounded-learning` writes distilled facts immediately; the proposed session uses a separate explicit opt-in policy, automatically saving eligible sourced candidates when automatic saving is enabled; review-before-saving remains an option. Do not silently change existing profiles; document the distinction and any later migration. Treat `recamem/web_teacher.py`'s current DNS pre-check followed by independent connection resolution as a potential TOCTOU risk, not an established rebinding defense; confirm with adversarial tests and harden before claiming safety.

## Session and capability
A typed ResearchSession records goal, permitted domains (optional narrower allowlist), policy, run ID, user consent, planner identity, budgets, state transitions and termination reason. State transitions: pending -> searching -> fetching -> reviewing -> completed/failed/cancelled; cancellation prevents new work and discards pending writes. Use configured search provider and deterministic policy first; a planner may propose bounded next queries and read-only navigation only if a real compatible model is available. Validate every proposal in deterministic code and never let page text grant permissions. If no planner is available, expose bounded static research as such, not as autonomous reasoning.

Start with static HTTP extraction. Consider an optional self-hosted Crawl4AI adapter using a security-reviewed, pinned patched version, only when installed and explicitly enabled. Chromium rendering has CPU/RAM and installation costs. No exposing arbitrary crawler configuration, scripts, CDP URLs, browser profiles, proxy settings, cookies, local files, downloads, or browser extensions. Use isolated ephemeral browser context with no credentials and no host filesystem access. Only read public pages; navigation and subresources all obey the same network and privacy policy. The library alone does not ensure egress protection. Browser mode must be disabled unless OS/network isolation or a mandatory proxy provably covers every request, including DNS, robots, redirects, frames, WebSockets and subresources. No unsafe fallback to direct browser networking. Do not expose arbitrary JS execution.

For static and browser fetching validate schemes, hostnames, ports and credentials, block loopback, private, link-local, multicast, non-global and IPv6 transition forms, metadata endpoints and redirects to them. Resolve and pin the validated public address to the actual connection while maintaining TLS hostname verification; ensure proxy/DNS rebinding cannot bypass controls. Apply the same broker to robots.txt and all auxiliary fetches. No access to local agent credentials, profile storage or service ports from the browser sandbox. Fail closed when isolation cannot be established.

Respect robots.txt as an operational policy with a descriptive user agent; robots is not a license or a substitute for terms/privacy review. On unavailable or ambiguous policy, stop and report the reason rather than bypass. Implement per-host rate and concurrency limits, Retry-After handling, bounded redirects, pages, queries, bytes, extracted chars, tokens, depth, duration, memory, retries and session count. Stop on budget exhaustion, cancellation, challenge, provider failure or network denial. Do not follow scraped URLs without policy checks.

## Evidence and memory
Return structured page records: original/final URL, title, timestamp, content hash, extraction method, content type, truncation, status, relevant text spans and per-claim citations. All source content and model output are untrusted data. Candidate facts carry provenance, are deduplicated, marked unverified and staged for policy validation and clearly marked unverified. Under the user-selected automatic-save policy, eligible candidates are saved via existing teach/supersession APIs without individual confirmation; review mode requires approval. No model weight update occurs. Rejected candidates do not write. Conflicts are surfaced without silent deletion. Never assert that citations verify a claim merely because a page was fetched. UI must show proposed actions, sources, costs, stop reason and any blocked/unavailable state.

## Evaluation and deployment
Offline deterministic fixtures simulate search, static and dynamic pages, denial, robots, redirects and malicious instructions; include DNS rebinding, private-address subresources, frames and cross-tool injection tests with instrumented local sinks. Tests prove no unauthorized connections or writes, not that prompt injection is solved. Live network tests require explicit consent and are separately reported; no external browsing is needed for unit tests. Measure extraction coverage, citation validity, time, memory and task completion against a static-only baseline on CPU. Preserve no-browser mode and explicitly report missing providers, dependencies, policy enforcement or capable model. Versions and security advisories must be reviewed at implementation time.
