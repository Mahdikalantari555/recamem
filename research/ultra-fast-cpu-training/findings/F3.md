# F3: Fast linear attention, recurrent fast weights, and Delta-rule training

## Findings

### [1] Dual-form mini-batching converts test-time gradient updates into high-throughput hardware matmuls
- quote: "Time complexity of the primal form within a TTT mini-batch is O(b x d^2). Time complexity of the dual form is O(b x d^2) for computing W_b alone, then an additional O(b^2 x d) for computing z_1,...,z_b... In our JAX implementation, training with the dual form is more than 5x faster than with primal."
- url: https://arxiv.org/html/2407.04620v4
- source_type: primary
- published: 2025-08-31
- confidence: high

### [2] Expressive hidden-state updates break the long-context perplexity plateau of classical RNNs
- quote: "Similar to Transformer, TTT-Linear and TTT-MLP can keep reducing perplexity by conditioning on more tokens, while Mamba cannot after 16k context. TTT-MLP still faces challenges in memory I/O, but shows larger potential in long context"
- url: https://arxiv.org/html/2407.04620v4
- source_type: primary
- published: 2025-08-31
- confidence: high

### [3] Titans models test-time associative memory as online gradient descent with surprise-momentum and weight decay
- quote: "We design this memory module so an event that violates the expectations (being surprising) is more memorable. To this end, we measure the surprise of an input with the gradient of the neural network with respect to the input in associative memory loss... Interestingly, we find that this mechanism is equivalent to optimizing a meta neural network with mini-batch gradient descent, momentum, and weight decay."
- url: https://arxiv.org/html/2501.00663
- source_type: primary
- published: 2024-12-31
- confidence: high

### [4] Gating and Delta-rule updates are mathematically complementary for associative capacity
- quote: "The number of orthogonal key-value pairs they can store is bounded by the model’s dimensionality. When the sequence length exceeds this dimension, 'memory collisions' become inevitable... gating enables rapid memory erasure while the delta rule facilitates targeted updates. Building on this insight, we introduce the gated delta rule and develop a parallel training algorithm"
- url: https://arxiv.org/html/2412.06464
- source_type: primary
- published: 2025-03-06
- confidence: high

### [5] Compact WY Householder representation eliminates the O(L x d^2) state materialization bottleneck
- quote: "P_{[t]}^j involves cumulative products of generalized Householder matrices, which could be optimized by the classical WY representation... Substituting these back into Eq. 3 yields a hardware-efficient chunkwise algorithm for DeltaNet that leverages matmuls, enabling tensor core based GPU optimization"
- url: https://arxiv.org/html/2412.06464
- source_type: primary
- published: 2025-03-06
- confidence: high

### [6] Vector-valued in-context learning rates and negative eigenvalues unlock regular language recognition beyond TC0
- quote: "RWKV-7 introduces a newly generalized formulation of the delta rule with vector-valued gating and in-context learning rates, as well as a relaxed value replacement rule. We show that RWKV-7 can perform state tracking and recognize all regular languages, while retaining parallelizability of training. This exceeds the capabilities of Transformers under standard complexity conjectures, which are limited to TC0."
- url: https://arxiv.org/html/2503.14456v2
- source_type: primary
- published: 2025-03-30
- confidence: high

### [7] MesaNet achieves one-shot optimal associative storage via online second-order least squares regression
- quote: "The Mesa layer is the optimal (in the squared-error sense) linear associative memory (Kohonen and Ruohonen, 1973), and it can store a new association instantaneously (one-shot), whereas DeltaNet requires in general multiple pattern presentations to reduce memorization error... DeltaNet only uses first-order derivative information to learn."
- url: https://arxiv.org/html/2506.05233
- source_type: primary
- published: 2026-06-03
- confidence: high

### [8] Mathematical FLOP asymmetry permits ultra-fast fast-weight state learning on CPU while capping full backpropagation
- quote: "Linear attention replaces the unbounded cache of softmax attention with a fixed-size recurrent state, reducing sequence mixing to linear time and decoding to constant memory... Every outer product is added to the state and none is removed... Eq. 5 is one online gradient step on the local regression loss 1/2 ||S^T k_t - v_t||_2^2"
- url: https://arxiv.org/html/2412.06464
- source_type: primary
- published: 2025-03-06
- confidence: high

## Dead ends
- "RWKV CPU training tokens per second Zen4": yielded only GPU cluster training logs (BlinkDL DeepSpeed A100/H100) and CPU inference benchmarks (rwkv.cpp), confirming standard backprop on 1B+ models on CPU is universally avoided.
- Direct search for "Hebbian associative memory CPU 1M tokens/minute": commercial and academic literature focuses exclusively on GPU tensor core chunkwise algorithms (Flash-Linear-Attention) rather than native CPU-optimized training implementations.

## Suggested follow-ups
- Benchmark single-core AVX-512 GEMV and outer-product throughput for updating 64x64 fast-weight states from cached token embeddings to verify the 100k tokens/sec CPU throughput threshold.
- Investigate whether MesaNet's Conjugate Gradient solver can be executed across CPU vector registers faster than rank-1 DeltaNet iterations under batched offline prompts.
- Evaluate memory collision error rates in 64-dim vs 128-dim head states when performing continual multi-needle retrieval across 1M token contexts without slow-weight fine-tuning.
