## Dead ends
- Direct C++ ggml computation graph hook injection from Python: attempting per-step callback interception (`ggml_backend_sched_eval_callback`) from Python drops generation throughput below 2 tokens/sec due to GIL contention and device synchronization barriers.
- In-place binary KV cache mutation without llama.cpp sequence APIs: directly writing into raw quantized KV memory (`q8_0` / `q4_0`) breaks cache stride alignment and tensor descriptor integrity; official `llama_memory_seq_*` functions must be used.
- Pure un-gated prompt stuffing: serializing large associative memory matrices directly as natural language triples degrades attention focus and exhausts the context window within multi-turn sessions.
