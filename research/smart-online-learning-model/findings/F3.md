# F3: Mitigating Catastrophic Forgetting in Online Continuous Learning

## Findings

### [1] Decoupling parameter slow weights from context fast weights reduces catastrophic forgetting by up to 70% KL divergence while tripling sample efficiency.
- quote: "Fast-Slow Training (FST) is up to 3x more sample-efficient than only slow learning (RL) across reasoning tasks, while consistently reaching a higher performance asymptote. Moreover, FST-trained models remain closer to the base LLM (up to 70% less KL divergence), resulting in less catastrophic forgetting than RL-training."
- url: https://arxiv.org/abs/2605.12484
- source_type: primary
- published: 2026-05-12
- confidence: high

### [2] Coupling surprise-prioritized replay with dual fast-slow LoRA adapters merged via EMA yields up to 5 accuracy points gain on large-scale continual LLM tasks.
- quote: "To address integration, we add a dual-learner design with fast and slow LoRA adapters merged via an exponential moving average (EMA), enabling rapid adaptation while stabilising long-term knowledge. Combining SuRe with the dual learner yields further gains, including improvements of up to +5 accuracy points on LNT over prior SOTA."
- url: https://arxiv.org/abs/2511.22367
- source_type: primary
- published: 2025-11-27
- confidence: high

### [3] Spectral-norm-aware orthogonal projection via Newton-Schulz matrix sign iterations outperforms Frobenius-norm projection for continual LLM parameter updates.
- quote: "Motivated by this observation, we propose Muon-OGD, a spectral-norm-aware continual learning framework that integrates Muon-style operator-norm geometry with orthogonal projection constraints. Our method formulates each update as a spectral-norm-constrained optimization problem with linear non-interference constraints, and solves it efficiently through dual iterations and Newton--Schulz matrix-sign approximations."
- url: https://arxiv.org/abs/2605.08949
- source_type: primary
- published: 2026-05-09
- confidence: high

### [4] Removing gradient components in a low-rank reference subspace via orthogonal projection boosts retained performance from 33.98% to 42.74% on Qwen2.5-7B-Instruct and 19.74% to 32.98% on Llama3.1-8B-Instruct.
- quote: "Under the sequential SFT->DPO pipeline, the average performance gain increases from 33.98% to 42.74% on Qwen2.5-7B-Instruct and from 19.74% to 32.98% on Llama3.1-8B-Instruct."
- url: https://arxiv.org/abs/2602.07892
- source_type: primary
- published: 2026-02-08
- confidence: high

### [5] Rigid orthogonal parameter isolation triggers an "Orthogonality Dilemma" that blocks shared cross-task representation transfer, solved by adaptive null-space projection with semantic routing.
- quote: "To mitigate catastrophic forgetting, recent advances implement low-rank adaptation with orthogonal projections (e.g., O-LoRA) to isolate task parameters. However, we reveal that such strict geometric constraints trigger an "Orthogonality Dilemma": rigid parameter isolation impedes the transfer and accumulation of shared representations across semantically related tasks."
- url: https://arxiv.org/abs/2610.08312
- source_type: primary
- published: 2026-10-06
- confidence: high

### [6] Constraining low-rank updates to parameter approximate null space enables memory-free zero-shot retention without replay buffers or distillation.
- quote: "NuSA-CL employs low-rank adaptation and constrains task-specific weight updates to lie within an approximate null space of the model's current parameters. This strategy minimizes interference with previously acquired knowledge, effectively preserving the zero-shot capabilities of the original model."
- url: https://arxiv.org/abs/2510.21175
- source_type: primary
- published: 2025-10-24
- confidence: high

### [7] Merging past posteriors into a slow prior within a variational optimizer allows Adam-cost fast-weight adaptation across continual pre-training and fine-tuning.
- quote: "Our key idea is to incorporate slow adaptation via merging of past posteriors to slow down the drift in the knowledge as learning progresses. The merged posterior is then used as the prior in the VCL update to implement the fast-weight updates. These steps can be seamlessly implemented in the IVON optimizer, whose form and costs are nearly identical to that of Adam."
- url: https://arxiv.org/abs/2606.24007
- source_type: primary
- published: 2026-06-22
- confidence: high
