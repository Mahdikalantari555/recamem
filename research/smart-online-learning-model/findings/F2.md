# F2: Online Plasticity, Surprise Gating, and Adaptive Retention

## Findings

### [1] Titans computes online memory updates via surprise gradients on associative loss, incorporating momentum over past surprise to prevent optimization stalls.
- quote: "To improve the above surprise metric (Equation 8), we break the surprise metric into (1) past surprise, which measures the surprise amount of a very recent past; and (2) momentary surprise, which measures the surprise of incoming data... S_t = \eta_t S_{t-1} - \theta_t \nabla\ell(M_{t-1}; x_t)"
- url: https://arxiv.org/html/2501.00663
- source_type: primary
- published: 2024-12-31
- confidence: high

### [2] Titans regulates finite memory capacity using an input-dependent adaptive forgetting gate that acts as dynamic weight decay.
- quote: "To better handle the limited memory, we present a decaying mechanism that consider the proportion of memory size and the amount of data surprise, resulting in better memory management... M_t = (1 - \alpha_t) M_{t-1} + S_t"
- url: https://arxiv.org/html/2501.00663
- source_type: primary
- published: 2024-12-31
- confidence: high

### [3] DeltaNet replaces additive memory accumulation with an error-correcting gradient step on recall loss to rebind keys in-place.
- quote: "This update rule is equivalent to a single step of stochastic gradient descent, training the state S_t at test time to output the desired values v_t for the keys k_t as inputs using loss L = 1/2 ||(S_t k_t - v_t)||^2 and gradient \partial L / \partial S = S k^T k - v^T k, leading to a recurrent update formula of S_t = S_{t-1}(I - a k_t^T k_t) + a v_t^T k_t"
- url: https://arxiv.org/html/2503.14456v2
- source_type: primary
- published: 2025-03-30
- confidence: high

### [4] The delta rule contracts state eigenvalues along the written key direction while leaving orthogonal dimensions unattenuated.
- quote: "The transition shrinks only the direction being written... S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top... Eigenvalue 1 orthogonal to k_t, 1 - \beta_t along it. \beta = 1: delete, then write. 0 < \beta < 1: blend. A decay forgets every direction; the delta rule forgets one."
- url: https://d2l.smola.org/slides/pytorch/chapter_recurrent-modern/deltanet.html
- source_type: secondary
- published: unknown
- confidence: high

### [5] Gated DeltaNet combines global topic clearance via scalar state decay with localized key rebinding via error-correcting delta updates.
- quote: "Gated DeltaNet: decay clears, the delta rule corrects... S_t = a_t S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top... a_t near 0: a new topic, clear everything. \beta_t near 1: rebind one key."
- url: https://d2l.smola.org/slides/pytorch/chapter_recurrent-modern/deltanet.html
- source_type: secondary
- published: unknown
- confidence: high

### [6] RWKV-7 upgrades scalar decay to channel-wise vector decay and scalar learning rates to vector in-context learning rates for dynamic state evolution.
- quote: "RWKV-7 introduces a newly generalized formulation of the delta rule with vector-valued gating and in-context learning rates, as well as a relaxed value replacement rule... S_t = S_{t-1}(\mathrm{diag}(w_t) - \hat{\kappa}_t^T(a_t \odot \hat{\kappa}_t)) + v_t^T k_t"
- url: https://arxiv.org/html/2503.14456v2
- source_type: primary
- published: 2025-03-30
- confidence: high

### [7] RWKV-7 decouples the removal key from the write key to prevent memory deletion from being constrained to the current input direction.
- quote: "Third, we decouple the keys at which the delta rule removes from and adds to the state... Our use of z_t and b_t in this extended formula permits a flexible approach to state update... One example of this flexibility is the ability to use a different removal key than replacement key."
- url: https://arxiv.org/html/2503.14456v2
- source_type: primary
- published: 2025-03-30
- confidence: high

### [8] Error-correcting recurrence write rules are mathematically isomorphic to Rescorla-Wagner associative learning, giving exact closed-form Kamin blocking.
- quote: "Writing linear attention as a state recurrence and comparing it with the corresponding learning rule gives a term-for-term identity (Section 2): the delta rule of DeltaNet... is Rescorla–Wagner... For the delta rule with rate \alpha \in (0,1) it is exactly 1 - (1-\alpha)^{p_1}, independently of p_2."
- url: https://arxiv.org/html/2508.08289
- source_type: primary
- published: 2026-08-28
- confidence: high

### [9] Pearce-Hall based PH-attention tracks a feature-indexed history of prediction error, enabling cue-specific learning rates that token-level scalar or vector gates cannot represent.
- quote: "Translating Pearce–Hall associability produces PH-attention, a write rule in which a feature-indexed history of prediction error yields cue-dependent learning rates, a state not maintained by the recurrent token-computed gates of Gated DeltaNet, GLA, Mamba-2, or Titans."
- url: https://arxiv.org/html/2508.08289
- source_type: primary
- published: 2026-08-28
- confidence: high

## Dead ends
- Generic KV cache eviction heuristics: search queries on streaming pruning returned fixed budget token dropping rather than continuous parametric plasticity.
- Classical Hebbian and decay-only attention (e.g., RetNet): unable to perform selective erasure or cue-specific blocking without wiping the entire state.

## Suggested follow-ups
- Investigate chunkwise parallel training pipelines (triangular solves vs Householder products) for maintaining exact numerical parity with streaming step-by-step surprise updates.
- Analyze eigenvalue stability bounds when allowing negative transition eigenvalues in RWKV-7 state evolution during long streaming sessions.
- Examine whether multi-layer recurrence stacks introduce spontaneous recovery of extinguished associations that single-state recurrences algebraically forbid.
