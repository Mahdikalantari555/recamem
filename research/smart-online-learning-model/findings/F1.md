# F1: Hybrid Pretrained SLM and Online Fast-Weight Delta Layers

## Findings

### [1] Memory as Context (MAC) prepends retrieved neural memory summaries directly into standard causal attention windows
- quote: "The core branch concatenates the corresponding long-term and persistent memories with the input sequence. Next, attention performs on the sequence and decides what part of the information should store in the long-term memory."
- url: https://arxiv.org/html/2501.00663v1
- source_type: primary
- published: 2024-12-31
- confidence: high

### [2] Memory as Gate (MAG) couples short-term sliding window attention and long-term fast weights via non-linear output gating
- quote: "We use sliding window attention (SWA) as a short-term memory and our neural memory module as a long-term memory, combining by a gating."
- url: https://arxiv.org/html/2501.00663v1
- source_type: primary
- published: 2024-12-31
- confidence: high

### [3] Layer-wise sequential stacking (MAL) bottlenecks representations compared to dual-branch context or gated memory integration
- quote: "The main drawback of this design is that the power of the model is limited by each of the layers and so it cannot take advantage of the complementary data processing of attention and neural memory module."
- url: https://arxiv.org/html/2501.00663v1
- source_type: primary
- published: 2024-12-31
- confidence: high

### [4] TTT inner-loop sequence modeling requires an internal LayerNorm and residual connection for stable forward execution
- quote: "For better stability during TTT, f always contains a Layer Normalization (LN) and residual connection. That is, f(x) = x + LN(f_res(x)), where f_res can be f_lin or f_MLP."
- url: https://arxiv.org/html/2407.04620v1
- source_type: primary
- published: 2024-07-05
- confidence: high

### [5] Input-dependent learning rate projection functions as a dynamic gradient gate for test-time updates
- quote: "We make \eta a function of the input token (therefore different across time) for additional flexibility. Concretely, we design \eta(x) = \eta_{base} \sigma(\theta_{lr} \cdot x)... Alternatively, \eta(x) can also be interpreted as a gate for \nabla \ell."
- url: https://arxiv.org/html/2407.04620v1
- source_type: primary
- published: 2024-07-05
- confidence: high

### [6] Surprisal-aware residual routing rescues exact token recall in fast-weight models via an alpha-clamped attention cache
- quote: "Output = TTT(x) + \alpha \cdot CacheAttention(x) ... we utilize a direct clamp parameterization for the gates: \alpha = clamp(\theta_{gate}, 0, \alpha_{max}), ensuring stable gradient flow during the critical cache-integration phase."
- url: https://arxiv.org/html/2603.06642v1
- source_type: primary
- published: 2026-02-26
- confidence: high

### [7] Two-stage curriculum training with frozen backbones prevents dying-gate collapse during residual side-tuning
- quote: "In the early stages of training, the TTT backbone produces uncalibrated representations. Consequently, the network minimizes its loss by forcing the \alpha gates to 0.0, effectively shutting off the cache and acting as a pure TTT model. We circumvented this using a Two-Stage Curriculum"
- url: https://arxiv.org/html/2603.06642v1
- source_type: primary
- published: 2026-02-26
- confidence: high

### [8] Hybrid interleaving of sliding-window attention with gated delta-rule layers resolves bounded memory capacity limits
- quote: "Linear transformers have limitations in modeling local shifts and comparisons, and their fixed state size makes it hard for retrieval tasks... Following recent hybrid architectures like Griffin... and Samba... we combine linear recurrent layers with sliding window attention (SWA), resulting in GatedDeltaNet-H1."
- url: https://arxiv.org/html/2412.06464v1
- source_type: primary
- published: 2024-12-09
- confidence: high

## Dead ends
- Unsupervised post-hoc weight splicing: searching for direct zero-shot insertion of fast weights into frozen SLMs without fine-tuning or distillation yielded no workable implementations; all viable models use two-stage training or continual pretraining.
- Pure un-gated delta memory scaling: literature confirms that without decay gating (alpha gate), pure delta rules experience memory saturation and catastrophic retrieval degradation beyond 2K-4K tokens.

## Suggested follow-ups
- How does chunk-level parallelization (e.g. Muon optimizer in LaCT vs dual-form matmuls) scale when applied to a frozen SLM's hidden activations during inference?
- What is the minimal rank and parameter budget for side-tuned delta-rule adapters (e.g., LST/Houlsby vs parallel fast-weight streams) to preserve base SLM reasoning while gaining streaming memory?
- What exact thresholding function (fixed percentile vs learned routing head) minimizes residual cache size while preventing needle forgetting?
